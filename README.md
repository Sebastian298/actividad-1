Desde esta carpeta, con Python 3:

```bash
python3 fibonacci_matrices.py
```

Ejecuta la verificación y la comparación.

```bash
python3 fibonacci_matrices.py 10
```

Muestra ambos métodos para el índice indicado. El índice debe ser un entero no negativo.

```bash
python3 fibonacci_matrices.py --verificar
```

Comprueba los índices 0, 1, 2, 5, 10 y 20.

```bash
python3 fibonacci_matrices.py --comparar
```

Compara el número de multiplicaciones de matrices y mide los tiempos.
